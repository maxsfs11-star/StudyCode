# O que é o StudyCode

O StudyCode não é apenas um aplicativo de cursos.

Também não é um catálogo de vídeos.

Também não é apenas uma coleção de exercícios.

O StudyCode nasce com um propósito muito maior.

Seu objetivo é ensinar programação de verdade.

Queremos formar desenvolvedores que compreendam o código, saibam interpretar problemas e consigam desenvolver autonomia.

Nosso objetivo não é ensinar o usuário a copiar código.

Nosso objetivo é ensinar o usuário a pensar como um programador.

---

# Nossa Filosofia

Todo conteúdo deve responder as seguintes perguntas:

• O que é?

• Para que serve?

• Por que existe?

• Quando utilizar?

• Quando NÃO utilizar?

• Quais problemas ele resolve?

• Como funciona internamente?

• Quais erros iniciantes costumam cometer?

• Como esse recurso é utilizado em projetos reais?

Nunca apresentar apenas uma sintaxe.

Sempre explicar o motivo da existência daquele recurso.

# Metodologia

Cada aula deverá seguir um padrão.

1. Introdução

Apresentação do assunto.

2. História

Como surgiu.

Por que surgiu.

O problema que resolveu.

3. Conceito

Explicação completa.

4. Sintaxe

Mostrar a estrutura.

5. Explicação linha por linha

Explicar absolutamente todos os elementos.

Exemplo:

- palavra-chave
- símbolos
- vírgulas
- ponto e vírgula
- parênteses
- chaves
- colchetes
- operadores
- aspas
- imports
- exports

Nada deverá ser considerado "óbvio".

Se um aluno pode ter dúvida, o StudyCode deverá explicar.

6. Exemplos simples

7. Exemplos reais

Mostrar utilização em projetos reais.

8. Erros comuns

Explicar os erros mais frequentes.

9. Curiosidades

Trazer fatos interessantes relacionados ao assunto.

10. Resumo

11. Exercícios

12. Desafios

13. Mini projeto

# Inteligência Artificial

A IA será um tutor.

Ela NÃO substituirá o aprendizado.

Ela NÃO deverá entregar respostas completas imediatamente.

Ela deverá incentivar o raciocínio.

Sempre que possível:

• fazer perguntas

• conduzir o aluno

• dar dicas

• sugerir o próximo passo

• incentivar a tentativa

• explicar os erros

• ensinar o conceito

Nunca incentivar copiar código sem compreensão.

A IA deverá atuar como um professor experiente.

Criar a plataforma de ensino de programação mais didática em língua portuguesa.

Ensinar desde o primeiro caractere digitado até conceitos avançados de desenvolvimento Full Stack.

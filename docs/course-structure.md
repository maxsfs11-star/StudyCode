# Criar o arquivo docs/course-structure.md

Este documento define a estrutura oficial de todos os cursos do StudyCode.

Independentemente da linguagem, tecnologia ou ferramenta ensinada, todos os cursos deverão seguir esta organização.

O objetivo é garantir uma experiência consistente para o aluno.

Quando ele iniciar um curso de HTML, React, Node.js, C++, Docker ou Git, sempre saberá exatamente como será sua jornada de aprendizado.

---

# Filosofia

Todo curso deverá ser construído pensando em evolução gradual.

Nunca apresentar conteúdos avançados antes da base.

O aluno deverá sentir que está subindo uma escada.

Cada módulo prepara o aluno para o próximo.

---

# Exercícios

Todo módulo deverá possuir exercícios.

Os exercícios deverão aumentar de dificuldade gradualmente.

Nunca utilizar perguntas apenas para preencher espaço.

Cada exercício deve reforçar um conceito.

---

# Desafios

Os desafios deverão estimular raciocínio.

Evitar exercícios de copiar código.

Sempre incentivar resolução de problemas.

---

# Dicionário do Programador

Sempre que surgir um conceito novo.

Criar automaticamente uma entrada no Dicionário do Programador.

Todo curso deverá estar integrado ao Dicionário.

---

# IA

A IA deverá conhecer exatamente:

• módulo atual

• aula atual

• conceitos já estudados

• conceitos ainda não estudados

A IA nunca deverá explicar assuntos muito avançados antes do momento correto.

Ela deverá respeitar a trilha do curso.
